# QuizMaster

Quiz interativo desenvolvido com HTML, CSS e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Perguntas e respostas
- Timer por questão
- Barra de progresso
- Sistema de pontuação
- Ranking local
- Reinício de partida
- Responsividade

## Conceitos Trabalhados

- Manipulação do DOM
- Eventos
- Arrays de Objetos
- Temporizadores
- Condicionais
- LocalStorage
- Controle de estado
